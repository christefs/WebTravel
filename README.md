# WebTravel
Development of a travel agency website using Tailwind, implemented responsively for two screen sizes: mobile with sizes up to 1024 px and desktop with sizes starting at 1025 px. Access is provided to a user profile page and dark screen modes are implemented.

It can be accessed at the following URL:
https://christefs.github.io/WebTravel/public/index.html
